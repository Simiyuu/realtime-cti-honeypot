# Real-Time Cyber Threat Intelligence Gathering and Visualization via Honeypot Deployment

## Overview
A localized, real-time cyber threat intelligence system that deploys honeypot 
sensors to capture, analyze and visualize live attack data targeting 
institutional networks.

## Stack
- Honeypot: Cowrie (SSH/Telnet) + Dionaea (Multi-protocol)
- Backend: Python (Flask/FastAPI)
- Database: MySQL
- Frontend: React.js
- Infrastructure: Oracle Cloud Free Tier VPS
- Containerization: Docker + Docker Compose

## Project Structure
- /honeypot - Honeypot configuration and Docker setup
- /backend - Python parser, enricher and API
- /dashboard - React frontend
- /data - Sample log files
- /docs - Project documentation
- /scripts - Setup and utility scripts
